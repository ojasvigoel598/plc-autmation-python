# Humanizer Context for PLC/SCADA Simulator

## Brand Samples

### Good Examples (use this voice)
- "This simulator runs a real PID loop against a physics model. Change a setpoint, and the level actually tracks it."
- "I built the PLC engine to match IEC 61131-3 scan cycles. Input scan, program scan, output update, every 100ms."
- "The leak detector catches tank leaks by comparing measured flows against level changes. It's simple, but it works."
- "Three tanks, three valves, one pump. Gravity does the work."

### Bad Examples (never write like this)
- "This cutting-edge platform leverages state-of-the-art technology to revolutionize industrial simulation."
- "The system seamlessly integrates multiple components to provide a comprehensive solution."
- "By harnessing the power of AI, we enable unprecedented levels of process visualization."

## Banned Phrases
- cutting-edge
- state-of-the-art
- seamlessly
- comprehensive
- leverage/leverages
- harness
- revolutionize
- robust (when describing basic features)
- enterprise-grade
- next-generation
- empower
- unlock
- transform
- disrupt
- innovative (unless describing something genuinely new)
- game-changing
- world-class
- best-in-class

## Writing Style Rules
- Use specific numbers, not vague claims
- Describe what it does, not what it "enables"
- Use simple, direct sentences
- Avoid jargon unless necessary for technical accuracy
- Write like an engineer explaining to another engineer
- Don't over-explain obvious things
